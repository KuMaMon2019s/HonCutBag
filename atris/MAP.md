## Architecture Overview

```
任意文本 → polished.mp4

Phase 1  导演规划     director_planner → director_plan.json (M1: 分场/情绪/过渡)
Phase 2  编剧引擎     text_parser → event_extractor → character_discoverer → adaptation_engine → storyboard_generator
Phase 2.5 故事板      seedream_client → storyboard.png + storyboard_images/S01-S10.png (M2: per-shot)
Phase 3  角色工厂     character_factory → 2×2 grid three-view → crop → front/side/back.png
Phase 4  编排器       orchestrator → shots/S01-S10/SHOT_META.json
Phase 5  视频生成     prompt_router (M4) → seedance_client (TOS + reference_image) → shots/S*/output.mp4
Phase 6  一致性守卫   consistency_guard + quality_gate + run_storyboard_review (M5: 4红线)
Phase 7  组装引擎     edit_decisions (trim + normalize + smart transition + xfade chain)
Phase 8  后期处理     audio_pipeline → visual_post → subtitle_burn → rhythm_editor → final_encode
全流程    产物链      artifact_chain (M6: checkpoint + --resume-from)
```

## Data Flow

```
input.txt
  → text_parser.parse_text() → segments[]
  → event_extractor.extract_events() → events[] (who/what/where/emotion)
  → character_discoverer.discover_characters() → CHARACTERS.json
  → adaptation_engine.adapt_events() → shots[] (承接上镜)
  → storyboard_generator.generate_storyboard() → STORYBOARD.json (三段式 prompt)
  → seedream_client → storyboard.png (per-shot)
  → character_factory.generate_character() → 2×2 grid → crop → front/side/back.png
  → orchestrator → shots/S01-S10/SHOT_META.json
  → seedance_client.submit(reference_image_base64) → shots/S*/output.mp4
      ├── tos_uploader.upload_image() → TOS signed URL
      ├── 429 退避重试 (30s/60s/120s)
      └── PrivacyInformation → 降级纯文本
  → consistency_guard + quality_gate → 质检报告
  → shot_embedder.embed_all_shots() → Qdrant vectors
  → smart_transition.decide_all_transitions() → 三层投票
  → edit_decisions.build + execute → trim + normalize + xfade
  → audio_pipeline → visual_post → rhythm_editor → final_encode
  → polished.mp4
```
