# HonCut 系统架构文档

## 系统概述

HonCut 是一个跨平台 AI 视频制作管线，采用 Mac（编排）+ Windows（GPU 生成）的分布式架构。

## 核心组件

### 1. Mac Pipeline 编排层

| Phase | 功能 | 说明 |
|-------|------|------|
| Phase 1 | 故事策划 | 剧本生成、故事结构 |
| Phase 2 | 分镜设计 | 镜头规划、画面描述 |
| Phase 3 | 角色设计 | 三视图生成（Seedream） |
| Phase 4 | 场景设计 | 参考图生成（Seedream） |
| Phase 5 | 视频生成 | 调用 Bridge 或直调 API |
| Phase 6 | 视频拼接 | 转场、合并 |
| Phase 7 | 音频处理 | TTS、音乐、混音 |
| Phase 8 | 字幕烧录 | 最终输出 |

### 2. 图像生成（Mac 本地）

| 组件 | 调用方式 | 说明 |
|------|----------|------|
| Seedream | 直调火山方舟 Ark API | 角色/场景/道具图生成 |
| 说明 | 图片生成不走 Bridge | 直接在 Mac 调用云端 API |

### 3. 视频生成（双轨路由）

| 路由 | 方式 | 说明 |
|------|------|------|
| Bridge（默认） | Mac → 192.168.31.221:9100 → Windows | 利用 Windows GPU |
| 直调（备选） | Mac → 火山方舟/Kling API | Bridge 不可用时 |

**环境变量配置：**
```bash
VIDEO_GENERATION_MODE=bridge    # bridge | direct
VIDEO_PROVIDER_SEEDANCE=bridge  # 按 provider 可配
VIDEO_PROVIDER_WAN=bridge
VIDEO_PROVIDER_KLING=direct
BRIDGE_API_URL=http://192.168.31.221:9100
```

### 4. InvokeAI 资产库（Windows）

| 资产类型 | 来源 | 用途 |
|----------|------|------|
| 角色三视图 | Panda (Seedream) | Phase 5 角色一致性 |
| 场景参考图 | Panda (Seedream) | Phase 5 场景背景 |
| 道具素材 | Panda (Seedream) | Phase 5 细节 |
| LoRA 模型 | 用户/社区 | 风格/角色定制 |
| Prompt 库 | Panda | 提示词管理 |
| 模型版本 | 用户 | 模型迭代追踪 |
| 生成历史 | 系统 | 回溯/复用 |

### 5. Bridge API（Windows）

| 端点 | 方法 | 说明 |
|------|------|------|
| /generate | POST | 提交视频生成任务 |
| /status/{task_id} | GET | 查询任务状态 |
| /download/{task_id} | GET | 下载生成的视频 |

## 数据流

```
Panda (Mac)
  │
  ├── Seedream API ──→ 生成图片资产
  │
  └── 上传到 InvokeAI (Windows)
        │
        └── 管理资产库
              │
              └── Phase 5 视频生成时查询资产
                    │
                    └── ComfyUI 使用资产生成视频
```

## 技术栈

| 组件 | 技术 | 位置 |
|------|------|------|
| Pipeline | Python 3.11 | Mac |
| 图像生成 | Seedream (火山方舟) | Mac → 云端 |
| Bridge | FastAPI | Windows |
| 视频生成 | ComfyUI + Wan2.2 | Windows |
| 资产管理 | InvokeAI | Windows |
| GPU | RTX 3070 Ti (8GB) | Windows |
