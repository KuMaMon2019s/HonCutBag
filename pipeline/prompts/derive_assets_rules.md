# 衍生资产提取规则（精简版）

> 来源: HonCut 内部规范 production_execution_derive_assets.md — 仅保留核心规则供 Phase 3 使用

## 核心原则

衍生资产是父资产的**视觉状态变体**（"{父资产名}·{状态名}"），不是独立物件。
判断标准: **稳定、可复用、资产级** — 仅在多个镜头/场次中持续成立，且改变角色整体识别外观时才创建。

## 提取范围

| 资产类型 | 是否衍生 | 提取范围 | 示例 |
|---------|---------|---------|------|
| 角色 | 是 | **仅变身状态**: ①服装 ②变身特效 ③变形 | 校服→战斗服、变身光效、兽化 |
| 场景 | 是 | **仅时间变体** | 日景→夜景、黄昏版 |
| 道具 | 否 | 不提取任何变体 | — |

## 角色衍生规则

三个方向（可并列）:
1. **服装** — 着装/装束整体改变（校服→战斗服/礼服/盔甲）
2. **变身特效** — 变身过程或形态切换时的光效、能量、粒子
3. **变形** — 体型/结构/整体形态改变（兽化、巨大化、异化）

**不衍生**: 局部特写、瞬时表情、可由 prompt 表达的局部质感、单镜头定格画面

## 场景衍生规则

仅提取「时间变体」— 同一场景不同时段的光照/色调/氛围变化（日景→夜景、黄昏、清晨）。
角度、天候、破坏等其它变化本阶段不提取。

## 字段规范

- `name`: 2~6 字，体现视觉外观变化（如 "战斗服"、"夜景"）
- `desc`: `[与默认态的差异] · [视觉特征]`，1~100 字
- `type`: 角色衍生填 `role`，场景衍生填 `scene`

## 检测逻辑（Phase 3 集成）

1. 读取 CHARACTERS.json
2. 对每个角色，检查 description/appearance 中是否包含变身/换装关键词
3. 关键词: 变身、换装、战斗服、礼服、盔甲、兽化、巨大化、变形、能量、光效
4. 如果检测到，生成衍生角色卡片（如 "主角·战斗服"）
5. 每个资产最多 1~5 个衍生，宁缺勿滥

## 来源优先级

剧本明确描写 > 资产描述暗示 > 合理推测
