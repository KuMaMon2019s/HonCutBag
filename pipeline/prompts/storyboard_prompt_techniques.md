# 分镜提示词技巧（精简版）

> 来源: HonCut 内部规范 storyboard_prompt_techniques.md — 仅保留核心技巧供 Phase 2.5 使用

## 核心原则

1. **画面描述是主干** — 分镜表「画面描述」字段的所有视觉元素必须完整保留，不得遗漏
2. **语义等价转换** — 只改变表达形式（中↔英、散文↔关键词），不改变语义
3. **禁止创意发散** — 不添加分镜表未提及的装饰性元素
4. **风格词从属于内容** — 风格/画质词是辅助修饰，不得反客为主

## 三段式提示词结构

```
【画面】→ 场景锚定 + 景别构图 + 画面描述完整转写 + 角色动作 + 朝向 + 情绪（信息密度最高）
【光影】→ 光源方向 + 色调倾向 + 明暗关系 + 质感细节（独立成段）
【风格】→ 风格锚定词 + 画质锁定词 + 禁止项（简短）
```

**篇幅分配**: 【画面】> 【光影】> 【风格】，风格词篇幅不可超过画面段。

## 景别词库

| 景别 | 中文提示词 | 英文提示词 |
|------|-----------|-----------|
| 大远景 | 大远景构图，环境全貌，人物渺小于场景 | extreme wide shot, establishing shot |
| 远景/全景 | 全身入镜，远景构图 | wide shot, full shot, full body |
| 中景 | 中景构图，人物膝盖以上入镜 | medium shot, cowboy shot |
| 近景 | 近景构图，上半身入镜，背景虚化 | medium close-up, upper body |
| 半身 | 半身构图，腰部以上，浅景深 | half body shot, bust shot |
| 特写 | 特写构图，面部或细节局部放大 | close-up, face focus |
| 大特写 | 大特写，极度局部细节 | extreme close-up, macro detail |
| 过肩镜 | 过肩构图，前景人物后背虚化 | over the shoulder shot |

**复合景别**: "远景→中景" 取起始端（大远景/远景）作为首帧构图。

## 朝向标注规则

| 朝向 | 中文 | 英文 |
|------|------|------|
| 正面 | 正面面朝镜头 | facing camera, front view |
| 3/4正面 | 3/4侧面微朝镜头 | three-quarter view facing camera |
| 正侧面 | 正侧面轮廓 | profile view, side view |
| 3/4背面 | 3/4侧背面 | three-quarter back view |
| 背面 | 背对镜头 | back view, from behind |

**获取优先级**: 分镜表「角色动作」字段 `｜朝向：` 标注 > 画面描述方位词 > 180°视轴线 > 景别暗示 > 情绪语义

## 人物位置连贯性

- **画面位置锁定**: 同角色同场景内左右位置固定
- **朝向守恒**: 对话场景遵循 180° 视轴线
- **变化须有动作衔接**: 位置/朝向变化必须在前序分镜中有位移/转身描写

## 画质降级禁用词

| 禁用 | 原因 | 替代 |
|------|------|------|
| film grain / 胶片颗粒 | 全图加噪点 | subtle cinematic texture |
| imperfect focus / 失焦 | 全图失焦 | 直接删除 |
| blurry background（滥用） | 主体跟着糊 | background bokeh, subject in sharp focus |
| 柔焦 / 朦胧感 | 降低整体锐度 | 直接删除 |

**核心**: 内容可以不完美，画质必须锐利。

## 画外文字 vs 画内文字

- **画外文字**（字幕、水印、UI文字）→ 绝对禁止
- **画内文字**（场景中的道具文字：匾额、书信、招牌）→ 属于场景道具，正常描述

## 首帧识别原则

| 画面描述类型 | 处理 |
|-------------|------|
| 静态瞬间（停步仰望） | 直接按描述生成 |
| 连续动作（挥剑斩下） | 取起始瞬间凝固态 |
| 镜头运动（缓推至中景） | 取起始端景别 |
