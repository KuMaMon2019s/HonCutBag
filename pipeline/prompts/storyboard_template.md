# 故事板提示词模板 (Storyboard Prompt Template)

## 模板说明

此模板用于生成 PREVIS 导演分镜故事板，确保每次生成的故事板都包含完整的视觉规范。

## 占位符说明

| 占位符 | 说明 | 默认值 |
|--------|------|--------|
| `{{STORYBOARD_CONTENT}}` | 分镜内容描述（场景、动作、情节） | 必填 |
| `{{CHARACTER_REFERENCE}}` | 角色参考描述（外观、特征） | 必填 |
| `{{PANEL_COUNT}}` | 面板数量 | 12 |
| `{{STYLE}}` | 风格描述 | 粗铅笔线条，细节最少，快速手势绘画能量 |

```
实际故事板绘画必须仅使用黑色和白色：{{STYLE}}，简单解剖结构构建和强烈的轮廓可读性。保持艺术作品轻量、动态和未完成，像早期分镜绘画。

## 注释颜色系统
- 红色箭头 = 身体运动
- 蓝色箭头 = 摄像机运动
- 绿色标记 = 构图/构图笔记
- 橙色标记 = 光线方向
- 紫色标记 = 歌声/情感强调
- 黑色文字 = 短焦镜头笔记和面板标签

- 仅使用黑白铅笔线条，粗犷快速的手势绘画风格

- 彩色注释系统必须清晰可见
- 电影式构图，专业分镜师风格
- 最高品质，细节丰富，清晰精致
```

## 使用说明

### 1. 填写占位符

在使用模板前，需要替换所有占位符：

**必填项：**
- `{{STORYBOARD_CONTENT}}`: 描述分镜的具体内容，包括场景、动作、情节发展
- `{{CHARACTER_REFERENCE}}`: 描述角色的外观特征，或说明"使用参考图像作为角色"

**可选项：**
- `{{PANEL_COUNT}}`: 面板数量，默认 12 个
- `{{STYLE}}`: 风格描述，默认为"粗铅笔线条，细节最少，快速手势绘画能量"

### 2. 面板布局建议

- **6-8 个面板**: 2 行 × 3-4 列
- **12 个面板**: 3 行 × 4 列（推荐）
- **16 个面板**: 4 行 × 4 列
- **20+ 个面板**: 考虑分成多个故事板

### 3. 内容描述技巧

`{{STORYBOARD_CONTENT}}` 应包含：
- 场景设置（地点、时间、氛围）
- 角色动作（起始姿态、运动方向、结束姿态）
- 镜头运动（推、拉、摇、移、跟）
- 情感节奏（紧张、舒缓、高潮）
- 关键对话或音效提示

## 常见问题

**Q: 面板数量可以超过 20 个吗？**
A: 可以，但建议分成多个故事板，每个故事板不超过 16 个面板，以保持画面清晰度。

**Q: 可以修改注释颜色系统吗？**
A: 不建议修改，这是行业标准，修改后可能影响专业分镜师的理解。

**Q: 风格描述可以完全自定义吗？**
A: 可以，但必须保留"粗铅笔线条"、"手势绘画能量"、"简单解剖结构"、"强烈轮廓可读性"等核心要素。

**Q: 如何指定镜头类型？**
A: 在 `{{STORYBOARD_CONTENT}}` 中明确说明，如"特写镜头"、"全景镜头"、"俯拍镜头"等。
